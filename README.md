# LabNote

LabNote hilft Kindern im Science-Unterricht dabei, ein Experiment-Protokoll
Schritt für Schritt zu erstellen: Fragestellung, Materialien, Durchführung,
Vermutung, Beobachtung und Ergebnis.

## Funktionen

- **Eigener Account** – Registrierung und Login, Daten werden lokal im
  Browser gespeichert (localStorage), kein Server nötig.
- **Geführter Wizard** – ein Schritt nach dem anderen mit Fortschrittsanzeige;
  die Vermutung kann übersprungen werden.
- **Protokoll-Übersicht** – alle bisherigen Protokolle mit Suche.
- **Kalender** – zeigt an, an welchen Tagen ein Protokoll erstellt wurde.
- **Profil** – eigene Statistik (Anzahl Protokolle, dabei seit).

## Entwicklung

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
